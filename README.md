# 日內交易風險與複利模型

一個在瀏覽器中運作的交易風險分析工具，可比較兩個策略、執行蒙地卡羅模擬、壓力測試與風險反推。

## 功能

- 比較兩組勝率、單筆風險與盈虧比
- 切換逐筆複利與固定 1R
- 10,000 次蒙地卡羅壓力測試與策略判讀
- 依目標最大回撤反推單筆風險
- 產生可分享的設定連結
- 在瀏覽器儲存策略，並可匯出或匯入 JSON 備份
- 數值更新與模式切換採用克制的介面動效，並尊重「減少動態效果」系統設定

網站上的計算與策略儲存都在使用者自己的瀏覽器中完成，不會上傳交易資料。

介面動效使用專案內附的 [GSAP 3.15.0](https://gsap.com/licensing/)，不依賴外部 CDN，因此下載後也能離線使用。

公開網站：<https://nwait-gg.github.io/trading-risk-calculator/>

> 本工具僅供風險分析與教育用途，不構成投資建議。
